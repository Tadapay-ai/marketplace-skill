# Security

Do not include private keys, recovery phrases, API tokens, personal records, or exploitable service details in public issues or pull requests.

Use GitHub's private vulnerability reporting feature if it is enabled for this repository. If it is unavailable, open an issue requesting a private reporting channel without including the vulnerability details. Wait for a maintainer to provide a channel before sharing sensitive information.

A report should identify the affected file or service behavior, impact, and minimal reproduction steps. Use synthetic data. Do not access other users' records, submit payments, or run disruptive tests to demonstrate a problem.

This repository contains discovery instructions and client configuration examples. The hosted MCP is a separate service. Report suspected service issues through a private channel as well.
